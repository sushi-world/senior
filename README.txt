복이네 골목 · 배포 방법 (3분)

1) 이 폴더(또는 zip)를 Netlify Drop(app.netlify.com/drop)에 끌어다 놓으면 주소가 바로 생겨요.
   예: https://bokee-alley.netlify.app
2) index.html 안의 https://YOUR-DOMAIN 을 그 주소로 바꿔요 (4곳, 찾기/바꾸기).
   그리고 var LINK="..." 의 주소도 같은 주소로 바꿔요.
3) 바꾼 파일로 다시 올리면 끝.
4) 카톡 미리보기가 예전 모양으로 나오면 developers.kakao.com/tool/debugger/sharing 에서
   주소를 넣고 "초기화"를 눌러요.
